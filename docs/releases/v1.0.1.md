A small update to **Lanes**: you can now forget an audio device you no longer use.

### What's new

**Forget unplugged devices.** Lanes remembers every output device it has seen,
so a DAC that's switched off keeps its place for when it's back. That also meant
a device seen only once - most often a monitor or TV's speakers, which Windows
offers while the display is connected over HDMI or DisplayPort - stayed in every
device picker as "unplugged" for good. Each unplugged device in **Audio devices**
now has a **Forget** button (click twice to confirm). It removes the device from
the fallback list and from every picker; any channel or profile that used it goes
back to the Windows default. If the device is connected again later, it simply
reappears as new.

For scripts and other tools there is a matching `forget_device` command in the
[local API](https://github.com/MAYBE-33/lanes/blob/main/docs/api.md). Nothing
else in the API has changed, and the
[Stream Deck plugin](https://github.com/MAYBE-33/lanes-streamdeck) 1.0.0 works
with this release unchanged.
