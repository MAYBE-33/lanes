The first release of **Lanes**: per-application audio channels for Windows.

Group your apps into channels - Game, Chat, Media, Aux, Mic and one of your own -
each with its own volume, mute and output device, all from one window. Lanes
manages Windows' own per-app settings rather than processing audio, so there is
no driver, no virtual device and no added latency.

### Download

| File | What it is |
| --- | --- |
| `Lanes-1.0.0-setup.exe` | The installer. Per-user, no administrator rights. **Start here.** |
| `Lanes-1.0.0-portable.zip` | The two executables, to run from any folder. Add an empty `portable.txt` beside them to keep settings there too |
| `SHA256SUMS.txt` | Hashes of the files above |

Windows 10 (1809) or later, 64-bit. Nothing else to install.
[Installation guide](https://github.com/MAYBE-33/lanes/blob/main/docs/install.md) ·
[Stream Deck plugin](https://github.com/MAYBE-33/lanes-streamdeck)

### This release is not code-signed yet

Windows SmartScreen may warn on first run ("More info" > "Run anyway"), and
**Smart App Control, if it is on, will block it**. Code signing through SignPath
Foundation is being set up - see
[code-signing.md](https://github.com/MAYBE-33/lanes/blob/main/docs/code-signing.md).

### Before uninstalling

Use **tray menu > Settings > Restore Windows audio settings** first: Windows keeps
the per-app settings Lanes changes after Lanes is gone.
